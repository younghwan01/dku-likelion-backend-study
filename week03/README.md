# 회원가입 프로그램

## 실습 주제
Java 첫걸음 시작하기 - 회원가입 프로그램

## 실습 내용
- 회원가입 프로그램(1)
- 회원가입 프로그램(2)
- 회원가입 프로그램(3)

## 구현 기능
- 회원가입 진행 여부 입력
- ID 입력
- 비밀번호 입력 및 비밀번호 확인
- 이름 입력
- 생년월일 6자리 입력 확인
- 이메일 입력
- HashMap을 이용한 회원 정보 저장
- ArrayList를 이용한 회원 목록 저장

## 사용한 Java 문법
- Scanner
- if 조건문
- while 반복문
- ArrayList
- HashMap
- equalsIgnoreCase()
- length()

## 배운 점
이번 실습을 통해 Java에서 사용자 입력을 받고 조건에 따라 프로그램 흐름을 제어하는 방법을 배웠다.  
또한 HashMap과 ArrayList를 사용하여 회원 정보를 저장하는 방법을 실습할 수 있었다.  
비밀번호 확인과 생년월일 자릿수 검사처럼 실제 회원가입 프로그램에서 필요한 기본 검증 과정도 구현해 보았다.
