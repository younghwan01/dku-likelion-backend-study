# Week 03 학습 정리

## 실습 주제
Java 첫걸음 시작하기 - 회원가입 프로그램

## 실습 내용
- 회원가입 프로그램(1)
- 회원가입 프로그램(2)
- 회원가입 프로그램(3)

## 구현 내용
- 회원가입을 진행할지 여부를 입력받도록 구현하였다.
- ID, 비밀번호, 이름, 생년월일, 이메일을 입력받는 기능을 작성하였다.
- 비밀번호와 비밀번호 확인 값이 일치하는지 검사하였다.
- 생년월일이 6자리인지 확인하는 조건문을 작성하였다.
- HashMap을 사용하여 한 명의 회원 정보를 저장하였다.
- ArrayList를 사용하여 여러 명의 회원 정보를 저장할 수 있도록 하였다.

## 사용한 Java 문법
- Scanner
- while 반복문
- if 조건문
- ArrayList
- HashMap
- equalsIgnoreCase()
- length()

## 배운 점
이번 실습을 통해 Java에서 사용자 입력을 받고 조건에 따라 프로그램 흐름을 제어하는 방법을 배웠다.  
또한 HashMap과 ArrayList를 사용하여 회원 정보를 저장하는 방법을 실습할 수 있었다.  
비밀번호 확인, 생년월일 자릿수 검사처럼 실제 회원가입 프로그램에서 필요한 기본 검증 과정도 구현해 보았다.
