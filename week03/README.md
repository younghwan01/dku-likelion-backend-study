# Week 03 학습 정리

## 학습 내용
- Git과 GitHub의 기본 개념을 학습하였다.
- 로컬 저장소와 원격 저장소의 차이를 이해하였다.
- git add, git commit, git push 명령어를 사용해 보았다.
- README.md 파일을 작성하고 GitHub에 업로드하는 과정을 실습하였다.

## 실습 내용
- 개인 스터디 Repository를 로컬 환경에 clone하였다.
- week03 디렉토리를 생성하였다.
- README.md 파일을 작성하였다.
- 작성한 파일을 GitHub Repository에 push하였다.

## 배운 점
이번 실습을 통해 GitHub에 파일을 올리는 전체 과정을 직접 해볼 수 있었다.  
처음에는 명령어가 헷갈렸지만, 디렉토리를 만들고 파일을 추가한 뒤 commit과 push를 하는 흐름을 이해할 수 있었다.
