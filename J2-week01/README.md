# J2-week01 - 자바로 구현하는 간단한 할 일 관리 서비스

## 학습 주제
멋쟁이사자처럼 `12가지 기술로 구현하는 APP서비스` 강의의 챕터 02 실습으로, Java를 이용해 간단한 할 일 관리 서비스를 구현했다.

## 구현 기능
- `add` : 새로운 할 일 추가
- `list` : 등록된 할 일 목록 조회
- `del` : 번호를 이용해 할 일 삭제
- `modify` : 번호를 이용해 기존 할 일 수정
- `exit` : 프로그램 종료

## 주요 학습 내용
### CRUD
애플리케이션의 기본 기능인 CRUD를 직접 구현했다.

- Create → `add`
- Read → `list`
- Update → `modify`
- Delete → `del`

### 사용자 입력 처리
`Scanner`와 `nextLine()`을 사용해 콘솔 입력을 받고, `trim()`으로 입력값 앞뒤의 불필요한 공백을 제거했다.

### ArrayList를 이용한 데이터 관리
`ArrayList<Todo>`에 할 일 객체를 저장했다. 배열과 달리 크기를 미리 정하지 않아도 되어 동적으로 할 일을 추가하고 삭제할 수 있다.

### 삭제와 검색
- `removeIf()`를 사용해 입력받은 id와 일치하는 할 일을 삭제했다.
- `stream().filter().findFirst().orElse(null)`을 사용해 수정할 할 일을 검색했다.

### 클래스와 메서드 분리
처음에는 `App`에 기능이 모여 있었지만 역할에 따라 클래스를 분리했다.

- `Main` : 프로그램 시작
- `App` : 명령어 입력 및 적절한 컨트롤러 호출
- `TodoController` : 할 일 추가/조회/수정/삭제 처리
- `SystemController` : 프로그램 종료 처리
- `Todo` : 할 일의 id와 content를 저장하는 객체

## 실행 예시
```text
명령) add
할일 : 축구
1번 할일이 생성되었습니다.
명령) list
번호 / 내용
1 / 축구
명령) modify
수정할 할일의 번호 : 1
기존 할일 : 축구
새 할일 : 풋살
1번 할일이 수정되었습니다.
명령) del
삭제할 할일의 번호 : 1
1번 할일이 삭제되었습니다.
명령) exit
앱 종료 명령이 입력되었습니다.
프로그램이 곧 종료합니다.
```

## 배운 점
이번 실습을 통해 콘솔 프로그램에서 사용자 입력을 받아 CRUD 기능을 구현하는 흐름을 익혔다. `ArrayList`, 람다식, 스트림을 이용해 데이터를 조회하고 수정하는 방법을 연습했으며, 기능을 컨트롤러로 분리하면서 하나의 클래스에 모든 로직을 넣는 것보다 역할별로 책임을 나누는 구조가 유지보수에 유리하다는 점을 배웠다.
