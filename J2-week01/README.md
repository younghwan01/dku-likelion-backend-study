# J2-week01 - 자바로 구현하는 할 일 관리 서비스

## 학습 목표

이번 주차에는 Java를 이용해 간단한 할 일 관리 서비스를 구현하면서 CRUD의 기본 개념을 학습했다.

사용자로부터 명령어를 입력받아 할 일을 추가, 조회, 수정, 삭제하는 기능을 구현하고, 이후 메서드와 Controller를 분리하면서 코드의 역할과 책임을 나누는 방법을 실습했다.

또한 Git/GitHub 및 IntelliJ 개발 환경을 설정하고 실습 코드를 Git으로 관리하는 방법도 함께 익혔다.

---

## 구현 기능

| 명령어 | 기능 |
| --- | --- |
| `add` | 새로운 할 일 추가 |
| `list` | 저장된 할 일 전체 조회 |
| `modify` | 특정 번호의 할 일 수정 |
| `del` | 특정 번호의 할 일 삭제 |
| `exit` | 프로그램 종료 |

프로그램은 다음과 같은 형태로 동작한다.

```text
명령) add
할일 : 축구
1번 할일이 생성되었습니다.

명령) add
할일 : 농구
2번 할일이 생성되었습니다.

명령) list
번호 / 내용
1 / 축구
2 / 농구

명령) modify
수정할 할일의 번호 : 1
기존 할일 : 축구
새 할일 : 풋살
1번 할일이 수정되었습니다.

명령) del
삭제할 할일의 번호 : 2
2번 할일이 삭제되었습니다.

명령) exit
앱 종료 명령이 입력되었습니다.
프로그램이 곧 종료합니다.
